# Functional Requirements

   ### Requester
   - Register/Login
   - Post a request
   - View quotes on a request
   - Accept a quote
   - Chat with accepted provider
   - Rate provider after completion

   ### Provider
   - Register with category + location
   - View matching open requests
   - Submit a quote
   - View accepted jobs

---

# Non-Functional Requirements

response time (requests should load within X seconds), the app should be usable on mobile browsers, passwords must be hashed, basic input validation on all forms, the app should handle at least X concurrent users without issue (even if you never test this at scale — stating the intention is what matters for the doc).
